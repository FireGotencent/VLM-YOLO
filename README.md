# VisionGuide LLM System

基于多模态大模型与YOLO目标检测的盲人避障导航系统

## 项目概述

本系统为视障人士提供一套低成本、高效率的智能导航解决方案。通过实时检测周围环境中的障碍物并以自然语言形式进行语音提醒，可以显著提升视障人士的出行安全性和独立性。

## 核心特性

- 🎯 **实时目标检测**: 基于 YOLOv8 的高效障碍物检测
- 🧠 **智能场景理解**: 多模态大模型进行语义推理和导航建议
- 🔊 **语音交互**: 自然语言语音提醒，支持语音指令输入
- 🔌 **灵活部署**: 支持本地 Ollama 和云端 API 双模式

## 快速开始

### 环境配置

```bash
# 激活虚拟环境
conda activate vgllm

# 安装依赖
pip install -r requirements.txt
```

### OpenAI 配置

- 桌面端配置位置：`config.yaml` → `llm.provider` / `llm.openai.base_url`
- 服务端配置位置：`server/config.yaml` → `llm.provider` / `llm.model` / `llm.base_url` / `llm.use_llm`
- API Key 配置位置：复制 `.env.example` 为 `.env`，设置 `OPENAI_API_KEY=...`（不要提交到仓库）

### 运行程序

```bash
python main.py
```

## 技术栈

- **目标检测**: YOLOv8 / Ultralytics
- **大语言模型**: Ollama / OpenAI / Claude / Gemini
- **语音合成**: pyttsx3
- **语音识别**: SpeechRecognition
- **图形界面**: PyQt6
- **数据处理**: OpenCV, NumPy
