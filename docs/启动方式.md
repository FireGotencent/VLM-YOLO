# VisionGuide LLM System — 启动方式

## 前置准备

```bash
# 激活 conda 环境（每次启动前执行）
conda activate vgllm

# 切换到项目根目录
cd D:\VisionGuide_LLM_System

# 复制并填写 API 密钥（首次）
copy .env.example .env
# 编辑 .env，填入 OPENAI_API_KEY 等
```

---

## 模式一：桌面端（本地全功能）

本地摄像头 + YOLO + LLM 全部在电脑上运行，PyQt6 图形界面。

```bash
python main.py
```

摄像头来源在 `config.yaml` 中切换：
- `type: local` — 使用电脑本地摄像头
- `type: ip_webcam` — 使用手机 IP Webcam App（同 WiFi）

---

## 模式二：服务端 + Web 客户端（手机浏览器）

手机用浏览器采集摄像头，发送给电脑处理。需要开两个终端。

### 终端 1：启动 WebSocket 服务端

```bash
python server/main.py
```

服务端监听 `wss://0.0.0.0:8765`（启用 SSL 后），等待客户端连接。

### 终端 2：启动 HTTPS 静态服务器

> 手机 Chrome 必须通过 HTTPS 才能访问摄像头。

```bash
python mobile/start_https_server.py
```

启动后打印手机访问地址：

```
HTTPS 服务器已启动
  局域网访问:  https://192.168.1.5:8443
  Tailscale:   https://100.111.x.x:8443
```

### 手机浏览器操作

1. 浏览器打开上面输出的地址
2. 首次访问提示证书不受信任 → 点「**高级**」→「**继续前往**」
3. 页面加载后：
   - WebSocket 地址填 `wss://<同一IP>:8765`
   - 点「连接服务端」→ 点「开启摄像头」

## 网络方案

| 场景 | 使用地址 |
|------|---------|
| 手机和电脑同一 WiFi | 局域网 IP（192.168.x.x） |
| 不同网络 / 4G | Tailscale IP（100.x.x.x），详见 [tailscale_setup.md](./tailscale_setup.md) |

## 常见问题

**手机提示"需要 HTTPS 才能访问摄像头"**
→ 改用 `python mobile/start_https_server.py` 启动服务，不要用 `python -m http.server`。

**WebSocket 连接失败**
→ 确认服务端已启动，防火墙放行 8765 端口，地址用 `wss://` 而非 `ws://`。

**证书警告无法绕过**
→ 在 Chrome 地址栏字面输入 `thisisunsafe`（不是粘贴到搜索栏）可强制放行。
