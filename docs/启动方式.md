# VisionGuide LLM System — 启动方式

## 前置准备

```bash
# 激活 conda 环境（每次启动前执行）
conda activate vgllm

# 切换到项目根目录
cd D:\VisionGuide_LLM_System

# 复制并填写 API 密钥（首次）
copy .env.example .env
# 编辑 .env，填入 OPENAI_API_KEY 等
```

---

## 模式一：桌面端（本地全功能）

本地摄像头 + YOLO + LLM 全部在电脑上运行，PyQt6 图形界面。

```bash
python main.py
```

摄像头来源在 `config.yaml` 中切换：
- `type: local` — 使用电脑本地摄像头
- `type: ip_webcam` — 使用手机 IP Webcam App（同 WiFi）
- `type: droidcam` — 使用 DroidCam App

---

## 模式二：服务端 + Web 客户端（手机浏览器）

手机用浏览器采集摄像头，发送给电脑处理，适合调试和日常使用。

### 第一步：启动 WebSocket 服务端（电脑）

```bash
python server/main.py
```

服务端监听 `ws://0.0.0.0:8765`，等待客户端连接。

### 第二步：启动 HTTPS 静态服务器（电脑）

> 手机 Chrome 必须通过 HTTPS 才能访问摄像头，不能用普通 HTTP。

```bash
python mobile/start_https_server.py
```

启动后会打印手机访问地址，例如：

```
HTTPS 服务器已启动
  本机访问: https://localhost:8443
  手机访问: https://192.168.1.5:8443
```

### 第三步：手机浏览器访问

1. 手机和电脑连同一 WiFi
2. 浏览器打开 `https://192.168.1.5:8443`（替换为实际 IP）
3. 首次访问会提示证书不受信任 → 点「**高级**」→「**继续前往**」
4. 页面加载后：
   - WebSocket 地址填 `ws://192.168.1.5:8765`
   - 点「连接服务端」→ 点「开启摄像头」

## 模式三：服务端 + Kivy 移动端

```bash
# 电脑启动服务端（同上）
python server/main.py

# 桌面运行 Kivy 客户端（测试用）
cd mobile
python main.py
```

打包 Android APK 见 [colab_build_apk.md](./colab_build_apk.md)。

## 跨网络访问（不同 WiFi / 4G）

使用 Tailscale 穿透，详见 [tailscale_setup.md](./tailscale_setup.md)。

连接后将上述 IP 替换为 Tailscale IP（如 `100.98.x.x`）即可，其余步骤不变。

## 常见问题

**手机提示"浏览器不支持摄像头 API"**
→ 用的是 HTTP 而不是 HTTPS。改用 `python mobile/start_https_server.py` 启动服务。

**WebSocket 连接失败**
→ 确认服务端已启动，防火墙放行 8765 端口，手机和电脑在同一网络。

**证书警告无法绕过**
→ 在 Chrome 地址栏输入 `thisisunsafe`（字面输入，不是粘贴到搜索栏）可强制放行。
