## 实验一：YOLO 目标检测性能

**目标**：获取 mAP、Precision、Recall、FPS 等指标，验证检测模型满足实时性要求。

### 方式 A：使用 COCO 公开数据集（推荐，标准做法）

首次运行会自动下载 COCO val2017（约 1 GB）：

```python
# scripts/eval_yolo_coco.py
from ultralytics import YOLO

model = YOLO("yolo26n.pt")
metrics = model.val(data="coco.yaml", split="val")

print(f"mAP50:     {metrics.box.map50:.4f}")
print(f"mAP50-95:  {metrics.box.map:.4f}")
print(f"Precision: {metrics.box.mp:.4f}")
print(f"Recall:    {metrics.box.mr:.4f}")
```

### 方式 B：自建校园场景数据集（更贴合实际部署环境）

1. 在校园内拍摄 100~200 张照片，覆盖走廊、路口、食堂等场景
2. 使用 LabelImg 标注（只需标注系统关注的 10 个类别）：

```bash
pip install labelImg
labelImg
```

3. 导出 YOLO 格式标注，按 8:2 划分训练/验证集，运行评估

## 实验二：端到端系统延迟

**目标**：测量从"发送帧"到"收到 TTS 文本"的全链路延迟，对比三种模式。

### 测量脚本

```python
# scripts/measure_latency.py
import asyncio
import base64
import json
import ssl
import statistics
import time

import cv2
import websockets


async def measure(url: str, n_frames: int = 100, use_ssl: bool = True):
    ctx = None
    if use_ssl:
        ctx = ssl.create_default_context()
        ctx.check_hostname = False
        ctx.verify_mode = ssl.CERT_NONE

    latencies = []
    cap = cv2.VideoCapture(0)

    try:
        async with websockets.connect(url, ssl=ctx, ping_interval=None) as ws:
            for i in range(n_frames):
                ret, frame = cap.read()
                if not ret:
                    break
                _, buf = cv2.imencode(".jpg", frame, [cv2.IMWRITE_JPEG_QUALITY, 70])
                payload = json.dumps({
                    "type": "frame",
                    "data": base64.b64encode(buf).decode()
                })
                t0 = time.perf_counter()
                await ws.send(payload)
                await ws.recv()
                latencies.append((time.perf_counter() - t0) * 1000)
                print(f"\r进度 {i+1}/{n_frames}", end="")
    finally:
        cap.release()

    print(f"\n\n{'='*40}")
    print(f"样本数:   {len(latencies)}")
    print(f"均值:     {statistics.mean(latencies):.1f} ms")
    print(f"中位数:   {statistics.median(latencies):.1f} ms")
    print(f"P95:      {sorted(latencies)[int(len(latencies)*0.95)]:.1f} ms")
    print(f"最大值:   {max(latencies):.1f} ms")
    print(f"{'='*40}")
    return latencies


if __name__ == "__main__":
    asyncio.run(measure("wss://localhost:8765"))
```

### 运行方式

分三次修改 `server/config.yaml` 后运行：

```bash
# 模式1：仅 YOLO，关闭 LLM
# server/config.yaml: use_llm: false, use_live: false
python scripts/measure_latency.py

# 模式2：YOLO + Gemma4 批量推理
# server/config.yaml: use_llm: true, use_live: false
python scripts/measure_latency.py

# 模式3：YOLO + Gemini Live API
# server/config.yaml: use_live: true
python scripts/measure_latency.py
```

## 实验三：导航建议质量主观评估

**目标**：评估 LLM 生成的导航文本在准确性、可操作性、简洁性三个维度的表现。

### 数据准备

用手机拍摄 15 张校园场景照片，分三类：

| 类别 | 数量 | 示例场景 |
|---|---|---|
| 畅通场景 | 5 张 | 空旷走廊、空旷操场 |
| 单一障碍 | 5 张 | 正前方有行人、侧边有自行车 |
| 复杂场景 | 5 张 | 多人、多障碍物 |

### 问卷设计

对每张图片，展示图片 + 系统生成的导航文本，请参与者评分（1~5 分）：

| 维度 | 题目 |
|---|---|
| **准确性** | 系统的描述与图片内容是否相符？（1=完全不符，5=完全相符） |
| **可操作性** | 你能根据这句话判断该怎么走吗？（1=完全不能，5=完全能） |
| **简洁性** | 这句话是否简洁，没有冗余信息？（1=非常冗余，5=非常简洁） |

可使用问卷星/腾讯问卷制作在线问卷，截图留存。

### 参与者

- 招募 10~15 名同学，无需为视障人士（注明"健视参与者模拟使用场景"）
- 每人完成全部 15 张图片的评分，约需 10~15 分钟

### 预期输出（填入论文表格）

| 场景类别 | 准确性 | 可操作性 | 简洁性 |
|---|---|---|---|
| 畅通场景 | | | |
| 单一障碍 | | | |
| 复杂场景 | | | |
| **总体均值** | | | |

格式：均值 ± 标准差，例如 `4.2 ± 0.6`。

## 实验四：距离估算精度分析

**目标**：量化基于检测框面积的启发式距离估算误差，为"局限性"章节提供数据支撑。

### 数据采集

用卷尺实测距离，在 0.5 m / 1.0 m / 1.5 m / 2.0 m / 3.0 m 各拍一张同一目标的照片，保存为：

```
data/distance_test/
  chair_0.5m.jpg
  chair_1.0m.jpg
  chair_1.5m.jpg
  chair_2.0m.jpg
  chair_3.0m.jpg
```

### 评估脚本

```python
# scripts/eval_distance.py
import cv2
from src.detection.yolo_detector import YOLODetector

detector = YOLODetector("yolo26n.pt", confidence=0.3)
detector.load()

test_cases = [
    ("data/distance_test/chair_0.5m.jpg", 0.5),
    ("data/distance_test/chair_1.0m.jpg", 1.0),
    ("data/distance_test/chair_1.5m.jpg", 1.5),
    ("data/distance_test/chair_2.0m.jpg", 2.0),
    ("data/distance_test/chair_3.0m.jpg", 3.0),
]

def estimate(det, frame):
    h, w = frame.shape[:2]
    ratio = det.area / (w * h)
    if ratio >= 0.20: return 0.8
    if ratio >= 0.10: return 1.2
    if ratio >= 0.05: return 2.0
    if ratio >= 0.02: return 3.0
    return 4.0

print(f"{'实测(m)':<10} {'估算(m)':<10} {'绝对误差':<10} {'相对误差'}")
print("-" * 45)
errors = []
for img_path, real_dist in test_cases:
    frame = cv2.imread(img_path)
    dets = detector.detect(frame)
    if not dets:
        print(f"{real_dist:<10} {'未检测到':<10}")
        continue
    est = estimate(dets[0], frame)
    abs_err = abs(real_dist - est)
    rel_err = abs_err / real_dist * 100
    errors.append(rel_err)
    print(f"{real_dist:<10.1f} {est:<10.1f} {abs_err:<10.2f} {rel_err:.1f}%")

if errors:
    import statistics
    print(f"\n平均相对误差: {statistics.mean(errors):.1f}%")
```

### 预期输出（填入论文表格）

| 实测距离 (m) | 估算距离 (m) | 绝对误差 (m) | 相对误差 (%) |
|---|---|---|---|
| 0.5 | | | |
| 1.0 | | | |
| 1.5 | | | |
| 2.0 | | | |
| 3.0 | | | |
| **均值** | — | | |

> 误差较大属于预期结果，在论文"局限性"中说明：当前采用基于检测框面积的启发式估算，未来可引入单目深度估计网络（如 MiDaS、Depth Anything）以提升精度。
